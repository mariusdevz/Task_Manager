# Task Manager

A responsive task management app built with HTML, CSS, and JavaScript. It helps users organize daily tasks, track completion, and manage their work in one place.

## Features

- **Add tasks:** Create tasks with a title, category, and due date.
- **Complete tasks:** Mark tasks as completed or active.
- **Filter tasks:** View all tasks, active tasks, or completed tasks.
- **Delete tasks:** Remove tasks you no longer need.
- **Persistent storage:** Tasks are saved in the browser using `localStorage`, so they remain available after refreshing the page.
- **Responsive design:** Layout adapts to desktop, tablet, and mobile screens.
- **Empty states:** Helpful messages appear when there are no tasks to display.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser `localStorage` API

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/mariusdevz/Task_Manager.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## How to Use

1. Enter a task title.
2. Select a category.
3. Choose a due date.
4. Add the task.
5. Mark tasks as completed when finished.
6. Use the filters to organize your task list.
